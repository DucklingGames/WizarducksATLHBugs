# Wizarducks and the Lost Hat Bugs

Please do report bugs here for problems you have found inside **Wizarducks and the Lost Hat.** You can also vote on and discuss bugs or requests that others have left.

Some things you should try:

## 1. Make sure the game and your graphics drivers are up to date, and validate install files on Steam

Some bugs may have already been fixed in later updates, and issues external to the game can cause bizarre problems that we won't be able to replicate.

If you're playing on Steam, you can validate the game's installation through the game properties. This can fix problems caused by a corrupted game installation.

## 2. Search for any existing report before you send one

Always search [the list of existing issues](https://github.com/DucklingGames/WizarducksATLHBugs/issues) and ensure your problem is not already reported, as responding to duplicates only slows us down. You can type your search terms into the query box at the top of the page.

If your issue is already reported you are welcome to add a comment/log/sample project onto that existing report - you can also leave a thumbs up to say you have this issue as well.

<br />

## 3. Choose the correct form and fill it all in

When [submitting a bug](https://github.com/DucklingGames/WizarducksATLHBugs/issues/new/choose), fill in each field with all pertinent information you can provide.

Send all requested information, otherwise there will be a delay while we request what's missing. Please include a screenshot or video if that helps explain the issue.
